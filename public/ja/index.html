Yanshi 偃师

AI ネイティブなヘッドレス描画エンジン——人と AI が同じキャンバスで一緒に創作するためのツールです。

  • 操作はアトムです。すべての編集はログに追記されるアトムであり、絵はそのログを折り畳んだ結果です。元に戻す／やり直しはポインタを動かすだけです。
  • 1つのカーネル、2つのホスト。同じ Rust カーネルがサーバーではネイティブに、ブラウザでは WebAssembly として動作するため、ローカル描画とサーバー描画は2つの近似ではなく、同一の実装です。
  • パッケージは自己完結。.yanshi パッケージはアトムのログと、それが参照するすべての blob を内包し、別の場所にインポートすれば同じ絵が再現されます。

このエンジンの上に MCP サーバーと Web ビューアがあり、エージェントと人が同じドキュメントを操作します。

インストール

プリビルド済みバイナリがあり、Rust ツールチェーンは不要です——Linux x86_64（静的）、Intel macOS、Apple Silicon に対応：

curl -fsSL https://raw.githubusercontent.com/gradetwo/yanshi/main/scripts/install.sh | sh

スクリプトはあなたのプラットフォーム向けのリリース資産を判別し、公式の SHA256SUMS で SHA256 を検証して、~/.local/share/yanshi/<バージョン> に展開し、yanshi-serve と yanshi-mcp の薄いラッパーを ~/.local/bin に置きます。パッケージは自己完結です：ブラシ、ブラシのプレビュー、メディア、パレット、テクスチャ、WASM カーネルがすべて入り、バイナリはパッケージ内レイアウト（bin/… と share/yanshi/… の並置）で資産を見つけるため、どこに展開しても動きます。

yanshi-serve --root ~/paint --doc mydoc --bind 127.0.0.1:8080   # その後 http://127.0.0.1:8080/ を開く
yanshi-mcp   --root ~/paint --doc mydoc                          # stdio MCP サーバー（MCP クライアント用）
yanshi-mcp   --list-tools --profiles core                        # ツール一覧だけを表示

調整用の変数：YANSHI_VERSION／YANSHI_PREFIX／YANSHI_BIN_DIR／YANSHI_DRY_RUN=1。プリビルド済みパッケージのないプラットフォーム（Linux arm64、Windows）は、ソースからビルドするか（cargo build --release -p yanshi-http -p yanshi-mcp、または make release）、リリースページから Windows パッケージを手動で展開してください。

クイックスタート

必要なのは Rust（rust-toolchain.toml で固定された stable ツールチェーン、rustfmt／clippy 付き）と make です。ブラウザカーネル（クライアント側レンダリング）を使う場合は rustup target add wasm32-unknown-unknown と wasm-bindgen-cli 0.2.129 も追加してください。なくてもサーバーは動作し、ビューアはサーバー側でレンダリングします。

git clone https://github.com/gradetwo/yanshi.git
cd yanshi
make dev        # ツールチェーンがあれば WASM カーネルをビルドし、ビルドして起動 ⇒ http://127.0.0.1:8110/

データは既定で ~/.local/share/yanshi/workspace に置かれます。ポートやデータルートを変える場合は環境変数で渡してください（make dev は Make 変数をレシピに渡しませんが、make serve は --port を明示的に渡します）：

PORT=9000 make dev
make serve PORT=9000

プッシュ前に make check（フォーマット、リント、テスト）を実行してください。全ターゲットは make help で見られます。

名前の由来

偃師（Yanshi）は『列子』「湯問」に登場する工匠で、歌い踊る機械人形を作ります。原文は次の通りです：

周穆王西巡狩，越昆侖，不至弇山。反還，未及中國，道有獻工人名偃師，穆王薦之，問曰：「若有何能？」偃師曰：「臣唯命所試。然臣已有所造，願王先觀之。」穆王曰：「日以俱來，吾與若俱觀之。」翌日，偃師謁見王。王薦之曰：「若與偕來者何人？」對曰：「臣之所造能倡者。」穆王驚視之，趨步俯仰，信人也。巧夫，顉其頤，則歌合律；捧其手，則舞應節。千變萬化，惟意所適。王以為實人也，與盛姬內御並觀之。技將終，倡者瞬其目而招王之左右侍妾。王大怒，立欲誅偃師。偃師大懾，立剖散倡者以示王，皆傅會革木膠漆白黑丹青之所為。王諦料之，內則肝膽心肺脾腎腸胃，外則筋骨支節皮毛齒髮，皆假物也，而無不畢具者。合會復如初見。王試廢其心，則口不能言；廢其肝，則目不能視；廢其腎，則足不能步。穆王始悅而歎曰：「人之巧乃可與造化者同功乎！」詔貳車載之以歸。夫班輸之雲梯，墨翟之飛鳶，自謂能之極也。弟子東門賈、禽滑釐聞偃師之巧以告二子，二子終身不敢語藝，而時執規矩。

出典：中国哲学書電子化計画『列子』「湯問」。ここでは簡体字で転記しています。

借りる価値があるのは巧みさではなく、構造と振る舞いが分離できることです。剖いてみれば、歌い踊る人形は革・木・膠・漆・顔料にすぎません。心・肝・腎を外せば、それぞれ語れず、見えず、歩けなくなります。そして組み直せば、元通りになります。

原文の結びは、人の巧が造化に匹敵するという穆王の感嘆です。私たちはそう主張しません。このプロジェクトは、道具の構造を書き記し、できることだけでなく、できないことも書きます。

Logo

マークはパチンコ（スリングショット）です。Y字の枠、2本のゴムバンド、赤い弾。映画『Who Cares』（《谁说我不在乎》）の一節に由来します：

抽出裤衩里的猴皮筋，做成弹弓打你们家玻璃。

（パンツのゴムを抜いてパチンコを作り、お前の家のガラスを割る）

bilibili のクリップ。映画の権利は原権利者に帰属します。

借りたのは冗談の中のあの動作——手元にあるもので使えるものを作ることです。プロジェクトの態度も同じです：構造を書き記し、使えるものは使い、使えないときはそう言う。
