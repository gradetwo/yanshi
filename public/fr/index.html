Yanshi 偃师

Un moteur de peinture headless, pensé pour l’IA — une toile où humains et IA créent ensemble.

  • Les opérations sont des atomes. Chaque modification est un atome ajouté à un journal, et l’image est le pliage de ce journal ; annuler et rétablir déplacent un pointeur.
  • Un noyau, deux hôtes. Le même noyau Rust fonctionne en natif sur le serveur et en WebAssembly dans le navigateur : le rendu local et le rendu serveur sont une seule implémentation, pas deux approximations.
  • Un paquet autonome. Un paquet .yanshi contient le journal d’atomes et tous les blobs qu’il référence ; l’importer ailleurs reproduit l’image à l’identique.

Au-dessus de ce moteur, un serveur MCP et une visionneuse web : un agent et un humain travaillent sur le même document.

Installation

Binaires précompilés, sans installer la chaîne d’outils Rust — Linux x86_64 (statique), macOS Intel et Apple Silicon :

curl -fsSL https://raw.githubusercontent.com/gradetwo/yanshi/main/scripts/install.sh | sh

Le script repère l’artefact de publication de votre plateforme, vérifie son SHA256 avec le SHA256SUMS officiel, le décompresse dans ~/.local/share/yanshi/<version> et dépose de minces lanceurs pour yanshi-serve et yanshi-mcp dans ~/.local/bin. L’archive est autonome : pinceaux, aperçus de pinceaux, médiums, palettes, textures et le noyau WASM sont inclus, et les binaires les retrouvent grâce à l’arborescence du paquet (bin/… à côté de share/yanshi/…) — elle fonctionne où que vous la décompressiez.

yanshi-serve --root ~/paint --doc mydoc --bind 127.0.0.1:8080   # puis ouvrez http://127.0.0.1:8080/
yanshi-mcp   --root ~/paint --doc mydoc                          # serveur MCP en stdio, pour les clients MCP
yanshi-mcp   --list-tools --profiles core                        # afficher seulement la surface d’outils

Réglages : YANSHI_VERSION, YANSHI_PREFIX, YANSHI_BIN_DIR, YANSHI_DRY_RUN=1. Plateformes sans paquet précompilé — Linux arm64 et Windows : compilez depuis les sources (cargo build --release -p yanshi-http -p yanshi-mcp, ou make release), ou décompressez à la main l’archive Windows depuis la page des publications.

Démarrage rapide

Il vous faut Rust (la chaîne stable épinglée par rust-toolchain.toml, avec rustfmt et clippy) et make. Pour le noyau navigateur (rendu côté client), ajoutez aussi rustup target add wasm32-unknown-unknown et wasm-bindgen-cli 0.2.129 ; sans eux, le serveur fonctionne quand même et la visionneuse rend côté serveur.

git clone https://github.com/gradetwo/yanshi.git
cd yanshi
make dev        # construit le noyau WASM si la chaîne d’outils est là, compile, sert ⇒ http://127.0.0.1:8110/

Les données vivent par défaut dans ~/.local/share/yanshi/workspace. Pour changer le port ou la racine des données, passez des variables d’environnement (make dev ne transmet pas les variables Make à sa recette, tandis que make serve passe --port explicitement) :

PORT=9000 make dev
make serve PORT=9000

Lancez make check (format, lint, tests) avant de pousser ; make help liste toutes les cibles.

État actuel

  • Version 0.3.2, avec des paquets de publication précompilés pour cinq plateformes (une ligne curl, voir ci-dessus) ; les sources sont sur GitHub et make release permet toujours de les empaqueter soi-même.
  • Le groupe d’outils semantic est réservé par décision et n’est pas implémenté.
  • Le noyau côté navigateur est un artefact de construction, absent d’un clone frais ; rien ne casse sans lui et la visionneuse repasse au rendu côté serveur.

D’où vient le nom

Yanshi (偃師) est l’artisan du Liezi, dans les « Questions de Tang », qui construit un automate chanteur et danseur. Le passage, dans l’original :

周穆王西巡狩，越昆侖，不至弇山。反還，未及中國，道有獻工人名偃師，穆王薦之，問曰：「若有何能？」偃師曰：「臣唯命所試。然臣已有所造，願王先觀之。」穆王曰：「日以俱來，吾與若俱觀之。」翌日，偃師謁見王。王薦之曰：「若與偕來者何人？」對曰：「臣之所造能倡者。」穆王驚視之，趨步俯仰，信人也。巧夫，顉其頤，則歌合律；捧其手，則舞應節。千變萬化，惟意所適。王以為實人也，與盛姬內御並觀之。技將終，倡者瞬其目而招王之左右侍妾。王大怒，立欲誅偃師。偃師大懾，立剖散倡者以示王，皆傅會革木膠漆白黑丹青之所為。王諦料之，內則肝膽心肺脾腎腸胃，外則筋骨支節皮毛齒髮，皆假物也，而無不畢具者。合會復如初見。王試廢其心，則口不能言；廢其肝，則目不能視；廢其腎，則足不能步。穆王始悅而歎曰：「人之巧乃可與造化者同功乎！」詔貳車載之以歸。夫班輸之雲梯，墨翟之飛鳶，自謂能之極也。弟子東門賈、禽滑釐聞偃師之巧以告二子，二子終身不敢語藝，而時執規矩。

D’après le Chinese Text Project, Liezi, « Tang Wen » ; transcrit ici en caractères simplifiés.

Ce qui mérite d’être emprunté, ce n’est pas l’habileté, mais le fait que la construction et le comportement sont séparables : ouvert, le personnage qui chante et danse n’est que cuir, bois, colle, laque et pigments ; ôtez-lui le cœur, le foie ou les reins et il ne peut plus parler, voir ou marcher ; remontez-le, et il est comme avant.

Le passage se termine par l’émerveillement du roi : un tel art pourrait rivaliser avec la nature. Nous ne prétendons pas cela. Le projet écrit comment l’outil est construit, et ce qu’il ne sait pas faire autant que ce qu’il sait faire.

Logo

La marque est un lance-pierre : un cadre fourchu, deux élastiques et une bille rouge. Elle s’inspire d’une réplique du film Who Cares (《谁说我不在乎》) :

抽出裤衩里的猴皮筋，做成弹弓打你们家玻璃。

(Sors l’élastique de ton slip et fais-en un lance-pierre pour casser les vitres de ta maison.)

Extrait sur bilibili ; les droits du film appartiennent à leurs détenteurs.

Ce qu’elle emprunte, c’est le geste d’une blague : faire quelque chose d’utilisable avec ce qu’on a sous la main. C’est l’attitude du projet : écrire la construction, utiliser ce qui marche, et le dire quand ça ne marche pas.
