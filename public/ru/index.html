Yanshi 偃师

ИИ-ориентированный headless-движок для рисования — холст, на котором люди и ИИ творят вместе.

  • Операции — это атомы. Каждое изменение — атом, добавленный в журнал, а изображение — свёртка этого журнала; отмена и повтор просто двигают указатель.
  • Одно ядро, два хоста. Одно и то же ядро на Rust работает нативно на сервере и как WebAssembly в браузере, поэтому локальный и серверный рендеринг — одна реализация, а не два приближения.
  • Пакет самодостаточен. Пакет .yanshi содержит журнал атомов и все blob-объекты, на которые он ссылается, и при импорте в другое место воспроизводит ту же картину.

Поверх этого движка работают MCP-сервер и веб-просмотрщик, поэтому агент и человек работают с одним документом.

Установка

Готовые бинарные сборки, тулчейн Rust не нужен — Linux x86_64 (статическая), macOS Intel и Apple Silicon:

curl -fsSL https://raw.githubusercontent.com/gradetwo/yanshi/main/scripts/install.sh | sh

Скрипт определяет релизный артефакт для вашей платформы, проверяет его SHA256 по официальному SHA256SUMS, распаковывает в ~/.local/share/yanshi/<версия> и кладёт тонкие обёртки для yanshi-serve и yanshi-mcp в ~/.local/bin. Пакет самодостаточен: кисти, превью кистей, материалы, палитры, текстуры и ядро WASM внутри, а бинарники находят их по структуре пакета (bin/… рядом с share/yanshi/…), поэтому всё работает, куда бы вы ни распаковали.

yanshi-serve --root ~/paint --doc mydoc --bind 127.0.0.1:8080   # затем откройте http://127.0.0.1:8080/
yanshi-mcp   --root ~/paint --doc mydoc                          # MCP-сервер через stdio, для MCP-клиентов
yanshi-mcp   --list-tools --profiles core                        # только показать список инструментов

Настройки: YANSHI_VERSION, YANSHI_PREFIX, YANSHI_BIN_DIR, YANSHI_DRY_RUN=1. Платформы без готовой сборки — Linux arm64 и Windows: соберите из исходников (cargo build --release -p yanshi-http -p yanshi-mcp или make release) либо вручную распакуйте пакет для Windows со страницы релизов.

Быстрый старт

Нужны Rust (стабильный тулчейн, зафиксированный в rust-toolchain.toml, с rustfmt и clippy) и make. Для браузерного ядра (рендеринг на клиенте) добавьте также rustup target add wasm32-unknown-unknown и wasm-bindgen-cli 0.2.129; без них сервер всё равно работает, а просмотрщик рендерит на стороне сервера.

git clone https://github.com/gradetwo/yanshi.git
cd yanshi
make dev        # собирает ядро WASM, если есть тулчейн, собирает и запускает ⇒ http://127.0.0.1:8110/

Данные по умолчанию лежат в ~/.local/share/yanshi/workspace. Чтобы сменить порт или корень данных, передавайте переменные окружения (make dev не пробрасывает Make-переменные в рецепт, а make serve явно передаёт --port):

PORT=9000 make dev
make serve PORT=9000

Перед отправкой запускайте make check (формат, линт, тесты); make help перечисляет все цели.

Текущее состояние

  • Версия 0.3.2, с готовыми релизными пакетами для пяти платформ (одна строка curl, см. выше); исходники на GitHub, а make release по-прежнему позволяет собрать пакет самостоятельно.
  • Группа инструментов semantic по решению только зарезервирована и не реализована.
  • Браузерное ядро — артефакт сборки, в свежем клоне его нет; без него ничего не ломается, а просмотрщик возвращается к серверному рендерингу.

Откуда взялось название

Яньши — мастер из «Ле-цзы» (глава «Вопросы Тана»), который строит механического артиста, умеющего петь и танцевать. Отрывок в оригинале:

周穆王西巡狩，越昆侖，不至弇山。反還，未及中國，道有獻工人名偃師，穆王薦之，問曰：「若有何能？」偃師曰：「臣唯命所試。然臣已有所造，願王先觀之。」穆王曰：「日以俱來，吾與若俱觀之。」翌日，偃師謁見王。王薦之曰：「若與偕來者何人？」對曰：「臣之所造能倡者。」穆王驚視之，趨步俯仰，信人也。巧夫，顉其頤，則歌合律；捧其手，則舞應節。千變萬化，惟意所適。王以為實人也，與盛姬內御並觀之。技將終，倡者瞬其目而招王之左右侍妾。王大怒，立欲誅偃師。偃師大懾，立剖散倡者以示王，皆傅會革木膠漆白黑丹青之所為。王諦料之，內則肝膽心肺脾腎腸胃，外則筋骨支節皮毛齒髮，皆假物也，而無不畢具者。合會復如初見。王試廢其心，則口不能言；廢其肝，則目不能視；廢其腎，則足不能步。穆王始悅而歎曰：「人之巧乃可與造化者同功乎！」詔貳車載之以歸。夫班輸之雲梯，墨翟之飛鳶，自謂能之極也。弟子東門賈、禽滑釐聞偃師之巧以告二子，二子終身不敢語藝，而時執規矩。

По изданию Chinese Text Project, «Ле-цзы», «Тан вэнь»; здесь приведено в упрощённых иероглифах.

Заимствовать стоит не мастерство, а то, что конструкция и поведение разделимы: вскрытая фигура, которая поёт и танцует, — это кожа, дерево, клей, лак и пигменты; уберите сердце, печень или почки — и она не сможет говорить, видеть или ходить; соберите обратно — и она как прежде.

Отрывок завершается восхищением царя: мастерство человека может сравниться с самой природой. Мы на это не претендуем. Проект записывает, как устроен инструмент, и чего он не умеет — так же честно, как и то, что умеет.

Logo

Знак — это рогатка: Y-образная рамка, две резинки и красный шарик. Вдохновлён репликой из фильма Who Cares (《谁说我不在乎》):

抽出裤衩里的猴皮筋，做成弹弓打你们家玻璃。

(Вытащи резинку из трусов, сделай рогатку и разбей окно в вашем доме.)

Фрагмент на bilibili; права на фильм принадлежат его правообладателям.

Заимствован жест из шутки — сделать пригодную вещь из того, что есть под рукой. Это и есть позиция проекта: записать конструкцию, использовать то, что работает, и честно говорить, когда не работает.
