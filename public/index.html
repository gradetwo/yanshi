偃师 Yanshi

AI Native 的 headless 绘画引擎，人与 AI 在同一张画布上协作的创作工具。

  • 操作原子化。每次编辑是一条原子、追加进日志；画面是这份日志折叠求值的结果。撤销与重做只移动指针。
  • 一份内核，两个宿主。同一套 Rust 内核在服务端原生编译、在浏览器编译为 WebAssembly ⇒ 本地渲染与服务端渲染是同一份实现，不是两份近似。
  • 工程包自包含。.yanshi 包带着原子日志与它引用的全部 blob，导进别处即可复现同一幅画。

在这套引擎之上是一个 MCP 服务端与一个 Web 查看器 ⇒ Agent 与人操作的是同一份文档。

快速开始

需要 Rust（rust-toolchain.toml 固定的 stable ✓，含 rustfmt/clippy）与 make。 要用浏览器端内核（客户端渲染）再装 rustup target add wasm32-unknown-unknown 与 wasm-bindgen-cli 0.2.129；不装也能跑，查看器退回服务端渲染。

git clone https://github.com/gradetwo/yanshi.git
cd yanshi
make dev        # 有工具链时构建 WASM 内核，构建服务端并启动 ⇒ 打开 http://127.0.0.1:8110/

数据缺省在 ~/.local/share/yanshi/workspace。换端口或目录请用环境变量 （make dev 不会把 Make 变量传进 recipe，而 make serve 是显式传 --port 的）：

PORT=9000 make dev
make serve PORT=9000

推送前跑 make check（格式、静态检查、测试）；全部目标见 make help。

名字的由来

「偃师」出自《列子·汤问》里造木偶的工匠。原文：

周穆王西巡狩，越昆侖，不至弇山。反還，未及中國，道有獻工人名偃師，穆王薦之，問曰：「若有何能？」偃師曰：「臣唯命所試。然臣已有所造，願王先觀之。」穆王曰：「日以俱來，吾與若俱觀之。」翌日，偃師謁見王。王薦之曰：「若與偕來者何人？」對曰：「臣之所造能倡者。」穆王驚視之，趨步俯仰，信人也。巧夫，顉其頤，則歌合律；捧其手，則舞應節。千變萬化，惟意所適。王以為實人也，與盛姬內御並觀之。技將終，倡者瞬其目而招王之左右侍妾。王大怒，立欲誅偃師。偃師大懾，立剖散倡者以示王，皆傅會革木膠漆白黑丹青之所為。王諦料之，內則肝膽心肺脾腎腸胃，外則筋骨支節皮毛齒髮，皆假物也，而無不畢具者。合會復如初見。王試廢其心，則口不能言；廢其肝，則目不能視；廢其腎，則足不能步。穆王始悅而歎曰：「人之巧乃可與造化者同功乎！」詔貳車載之以歸。夫班輸之雲梯，墨翟之飛鳶，自謂能之極也。弟子東門賈、禽滑釐聞偃師之巧以告二子，二子終身不敢語藝，而時執規矩。

据 中国哲学书电子化计划《列子·汤问》；此处按简体转录。

值得借来做名字的，不是"巧"，而是构造与行为是分开的：剖开看是"革木胶漆、白黑丹青"；拆掉心肝腎，它分别不能言、不能视、不能步；而"合会"之后，又和当初一样。

原文结尾是穆王的赞叹——"人之巧乃可与造化者同功乎"。这一句我们不当真：这个项目只是把构造写清楚，做不到的也照样写在文档里。

Logo

标记是一个弹弓：Y 形的杈，两根蓝色皮筋，一颗红色弹丸。灵感来自电影《谁说我不在乎》里的一句台词：

抽出裤衩里的猴皮筋，做成弹弓打你们家玻璃。

片段（bilibili）；影片版权属原权利人。

借的只是一句玩笑话里那个动作——用现成的东西做一件能用的东西。与项目本身的态度一致：把构造讲清楚，能用就用，不能就说不能。
