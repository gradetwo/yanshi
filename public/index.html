偃师 Yanshi

一个无头（headless）绘画引擎：只追加的原子日志、由日志折叠求值出的状态、纯 Rust 渲染计算内核、零依赖的 HTTP/WebSocket 服务端，以及一个最小的 Web 查看器。同一份内核在服务端原生编译，在浏览器里编译为 WebAssembly。

名字的由来

「偃师」出自《列子·汤问》里造木偶的工匠。原文：

周穆王西巡狩，越昆侖，不至弇山。反還，未及中國，道有獻工人名偃師，穆王薦之，問曰：「若有何能？」偃師曰：「臣唯命所試。然臣已有所造，願王先觀之。」穆王曰：「日以俱來，吾與若俱觀之。」翌日，偃師謁見王。王薦之曰：「若與偕來者何人？」對曰：「臣之所造能倡者。」穆王驚視之，趨步俯仰，信人也。巧夫，顉其頤，則歌合律；捧其手，則舞應節。千變萬化，惟意所適。王以為實人也，與盛姬內御並觀之。技將終，倡者瞬其目而招王之左右侍妾。王大怒，立欲誅偃師。偃師大懾，立剖散倡者以示王，皆傅會革木膠漆白黑丹青之所為。王諦料之，內則肝膽心肺脾腎腸胃，外則筋骨支節皮毛齒髮，皆假物也，而無不畢具者。合會復如初見。王試廢其心，則口不能言；廢其肝，則目不能視；廢其腎，則足不能步。穆王始悅而歎曰：「人之巧乃可與造化者同功乎！」詔貳車載之以歸。夫班輸之雲梯，墨翟之飛鳶，自謂能之極也。弟子東門賈、禽滑釐聞偃師之巧以告二子，二子終身不敢語藝，而時執規矩。

据 中国哲学书电子化计划《列子·汤问》；此处按简体转录。

值得借来做名字的，不是"巧"，而是构造与行为是分开的：那个能唱能舞的东西，剖开看是"革木胶漆、白黑丹青"；拆掉心肝腎，它分别不能言、不能视、不能步；而"合会"之后，又和当初一样。

  • 日志即构造。每次编辑是一条原子，追加进日志；画面是把它折叠求值的结果。
  • 拆开再装上，结果不变。.yanshi 工程包连同日志引用到的全部 blob 一起装走，导进另一个工作区后逐字节一致。
  • 行为出自同一份内核。服务端原生与浏览器 WebAssembly 是同一份实现，不是两套各自近似的东西。

原文结尾是穆王的赞叹——"人之巧乃可与造化者同功乎"。这一句我们不当真：这个项目只是把构造写清楚，做不到的也照样写在文档里。

Logo

标是一个弹弓：Y 形的杈，两根蓝色皮筋，一颗红色弹丸。灵感来自电影《谁说我不在乎》里的一句台词：

抽出裤衩里的猴皮筋，做成弹弓打你们家玻璃。

片段（bilibili）；影片版权属原权利人。

借的只是一句玩笑话里那个动作——用现成的东西做一件能用的东西。这与项目本身的态度一致：把构造讲清楚，能用就用，不能就说不能。

设计取向

  • 日志即真相。每次编辑写成一条原子，追加进日志；当前状态由日志折叠求值得到。撤销与重做只移动指针，不是"把操作反过来做一遍"。
  • 一份内核，两处运行。拖动时的乐观预览与最终落笔是同一份实现，不是两套代码各自近似。
  • 确定性。同样的输入得到同样的输出。导出与重放有逐字节比对的测试守着。
  • 可搬走。.yanshi 工程包是未压缩 tar，内含原子日志、文档元数据、日志引用到的全部 blob，以及导出时当场渲染的一份 HEAD 预览。任何系统的 tar 都能列出与解开。

工具面

--profile all 一个词开启全部已实现的组：114 个工具（只开 core 是 46 个）。图层混合模式按渲染层那份清单校验，不认识的名字会被明确拒绝并列出可用值，而不是写进日志之后被静默忽略。

当前状态

  • 版本 0.1.0，尚无已发布的发行版。源码从 GitHub 取得，make release 自行打包（带校验和）。
  • semantic 工具组按既定裁定只作预留，未实现。
  • appearance.texture 的纸纹是近似水彩纸与画布，可调；但没有专门的"粗纹水彩纸 / 帆布纹理"预设。
  • 浏览器端内核是构建产物，新克隆的仓库里没有它。缺了它不会报错，查看器会退回服务端渲染；要本地渲染就按 README 构建。
