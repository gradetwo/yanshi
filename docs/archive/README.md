# archive —— **一次性现场记录**的去处

这里是**某轮排查／验证的现场快照**（外部审计点名"过程文档挤在 `docs/` 顶层"⇒ 05 复审 NEW-M5 ✓）。
**规矩**（同一事实只写一处 ⇒ 只在这里 ✓）：

- 收什么：**当时有用、之后不再被引用**的现场记录 —— 每条带日期与结论，**只追加不改写** ✓
  （改写会毁掉"当时看到的是什麼"这条证据 ✗）。
- 不收什么：**仍在生长的台账**（如 `surface-alignment.md`）、**面向使用者的文档**
  （`guide*.md`／`tools.md`／`samples.md`／`semantic-tools.md`／`releases/`）⇒ 那些留在 `docs/` ✓。
- 移进来之前：`grep -rl <文件名> --exclude-dir=.git --exclude-dir=target .` ⇒ **引用数必须为 0**
  或**逐处改掉**（链接断了没有信号 ✗）。
