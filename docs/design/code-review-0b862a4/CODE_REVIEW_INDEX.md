## 报告导航

1. [**00. 架构审查与全景评估总览报告（Executive Summary）**](code-review/00-OVERVIEW.md)
   - 总体审查结论、技术评级矩阵（A~F）、Top 10 最致命缺陷一览表、三阶段战略演进路线。

2. [**01. AI MCP 调用创作与反复修改专项审查**](code-review/01-mcp-ai-creation.md)
   - **MCP 协议合规**：Stdio 换行切片导致的反序列化崩溃 [MCP-001]、未协商协议版本。
   - **LLM 认知负载**：114 个工具致上下文膨胀（30k tokens）、参数命名与层级割裂 [MCP-004]。
   - **颜色歧义炸弹**：0..1 与 0..255 启发式推断导致微暗色被瞬间放大 255 倍纯亮色 [MCP-002]。
   - **反复修改工作流**：烘焙介质笔触无法重放微调 [MCP-006]、预览图受限 512px 细节失真。

3. [**02. 人类 Web 创作体验与前端交互架构专项审查**](code-review/02-web-human-creation-ux.md)
   - **绘画手感卡顿**：每枚 dab 同步调用 `getImageData(1, 1)` 引发硬件管线停顿与严重掉帧 [WEB-001]。
   - **交互逻辑死锁**：滚轮事件被彻底屏蔽（吞没），但界面提示却教用户用滚轮放大 [WEB-002]。
   - **数位板缺陷**：丢失 `getCoalescedEvents` 导致高速画弧线呈折线锯齿 [WEB-003]、无倾斜角。
   - **网络盲画**：选用 `.myb` 笔刷时本地渲染被旁路，拖动期无墨，抬手等网络返回 [WEB-004]。
   - **专业软件差距**：与 Krita/Photoshop 相比在拾色器（无 HSV 环）、选区、变换、图层组上的残缺。

4. [**03. 核心数据模型、CRDT 与持久化架构专项审查**](code-review/03-core-data-model-persistence.md)
   - **算法退化死代码**：`can_extend` 中包含未使用的 `compute_suppressed` 全量历史扫描，增量折叠退化为 $O(N\log N)$ [CORE-001]。
   - **存储与 GC 风险**：并发 Blob 上传与 GC 存在竞态条件，未引用 Blob 可能被永久误删 [CORE-002]。
   - **长会话膨胀**：缺乏日志压缩（Log Compaction），长时会话内存与冷启动无界增长 [CORE-003]。
   - **浮点一致性**：x86/ARM/WASM 跨架构 IEEE 754 细微差异与 D0 逐位一致性承诺的矛盾 [CORE-005]。

5. [**04. 渲染管线与笔刷动力学引擎专项审查**](code-review/04-render-brush-engine.md)
   - **文本渲染致命缺陷**：仅内置 5×7 ASCII 点阵，**所有中文（CJK）与 Emoji 强制渲染为问号 `?`** [RND-001]。
   - **纯 CPU 单线程瓶颈**：缺乏 SIMD 指令级向量化与多核切片渲染，4K 分辨率帧率崩溃 [RND-002]。
   - **专业色彩断层**：8-bit 离散量化导致大渐变与模糊呈现严重色带（Banding）[RND-003]；无 ICC/CMYK。
   - **瓦片缓存抖动**：默认 64MB L3 瓦片缓存过小，4K 画布下仅能容纳单层一屏，多图层剧烈抖动 [RND-004]。
   - **PSD 互通残缺**：仅支持单层扁平图只读导入，完全无法导出 PSD [RND-005]。

6. [**05. WASM 介质插件与物理仿真专项审查**](code-review/05-wasm-medium-plugins.md)
   - **伪 WASM 沙箱**：服务端原生未运行 WASM 解释器，而是将 6 个介质 C ABI 静态硬写死进二进制，无动态扩展能力 [MED-001]。
   - **全局并发锁**：宿主引入全局互斥锁 `MEDIUM_LOCK`，所有介质绘制被全局单线程串行化 [MED-002]。
   - **物理仿真失真**：油画缺少高度图（Heightmap）与法线高光（无厚涂立体感）；水彩缺少毛细流体模拟（呈现串珠状色斑）。
   - **二进制污染**：`.wasm` 产物被纳入版本控制且处于 modified 脏状态 [MED-005]。

7. [**06. 网络服务、网络安全与运维架构专项审查**](code-review/06-http-security-ops.md)
   - **P0 任意文件写入**：`export_png` 与 `export_project` 接收未受限绝对路径，直接 `std::fs::write` 覆盖系统文件 [SEC-001]。
   - **P0 任意文件读取**：`import_project` 直接 `std::fs::read` 任意路径 [SEC-002]。
   - **P0 鉴权全开越权**：`/api/documents` 匿名无密码签发最高权限 Editor 令牌 [SEC-003]。
   - **P1 跨站 WebSocket 劫持**：握手未校验 `Origin` 请求头，恶意网页可窃取或篡改画布 [SEC-004]。
   - **DoS 拒绝服务**：每连接一线程，默认封顶 64 连接，无 Slowloris 防护易被极速占死 [SEC-005]。

8. [**07. 专业绘画/作图软件定位与工程质量专项审查**](code-review/07-product-positioning-engineering.md)
   - **设计与实现偏离**：对象组嵌套被显式硬编码拒绝、开放 WASM 介质未落地、语义工具未开发。
   - **单文件代码债务**：`tools.rs`（12,235 行）、`viewer.rs`（7,864 行）、`implementation-notes.md`（11,432 行）。
   - **零依赖反噬**：手写轮子引发安全漏洞（路径覆盖）与功能残缺（点阵字）。
   - **演进路线图**：安全止血 -> 交互重构与工程拆解 -> 专业色彩与真 WASM 沙箱。
