## 二、三段分解的**形式**（【设计】✓，借 GIMP projection／Krita per-node ✓）

对**每一个 tile**（不是整幅 ✓）与**当前层索引 i** ✓：

```
result = composite( below[i], layer[i], above[i] )
```

* **below[i]** ＝ 第 `0..i−1` 层的合成 ✓（**本文要缓存的** ✓）；
* **layer[i]** ＝ 当前层**本身**的渲染 ✓（有它自己的 bitmap 缓存 ✓）；
* **above[i]** ＝ 第 `i+1..N−1` 层的合成 ✓ —— **只有当前层半透明时才需要** ✓（否则可短路 ✓）。

**∴ 三个不变量**（判据就钉它们 ✓）：
1. **缓存命中不得改变输出** ✓（**逐字节相同** ✓）；
2. **below 只在"它下面那些层"没变时才能复用** ✓（**否则必须失效** ✓ = 防撒谎 ✓）；
3. **命中时不得触发任何额外渲染** ✗（第 358 轮教训 ✓：**不许"预渲一遍来判断"** ✓ ——
   渲染**不幂等** ✓：累加告警 ✓、heal／liquify 有状态 ✓ ⇒ 曾致 **5 个测试红** ✓）。

### 10.2 ∴ 块化的真实代价 ✓（**公式** ✓）

| 512² | 128 | 768 | 2.25× ✗ |

1. **解 `((s+2b)/s)² ≤ 1.5` ⇒ `s ≥ 8.9 b`** ✓ ⇒ **∴ `b = 128` 时块要 ≥ ~1140 px 才不亏** ✓
