# 设计文档目录

本目录存放**冻结的设计修订**。设计文档是偃师全部语义与协议的权威定义，代码是它的实现翻译。

- 当前冻结修订：[yanshi-v1.0-draft4.md](yanshi-v1.0-draft4.md)（版本 v1.0-draft4，冻结候选版）。
- 历史修订保留在同一目录，文件名包含版本号；不要就地覆盖旧修订的语义内容，新修订建立新文件。
- 仓库内副本与源文档保持一致，仅额外标注来源行。

## 与代码的关系

**代码不得与设计文档静默分叉。** 任何行为变更都必须在本目录的设计文档中先体现，并在同一个 PR 中同步实现与测试：

1. 先更新设计文档，说明动机与对既有语义的影响。
2. 在同一 PR 中修改代码并补充测试（折叠与 GC 语义必须附属性测试）。
3. PR 中显式说明文档与代码的对应关系。

若实现过程中发现设计文档存在笔误或表述歧义，直接在 PR 中修正文档并注明；若属于改变协议的语义变更，需独立评审后再落地。

参见 [CONTRIBUTING.md](../../CONTRIBUTING.md) 的“设计文档变更流程”。
