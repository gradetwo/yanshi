## 六、写示例时必须知道的一个仓库陷阱

**`r#"…"#` 原始字符串遇到 `"#` 就提前结束** —— 而 JSON 里写颜色 `"#ff0000"` 恰好包含这两个字符，
于是整个 `tools.rs` **不再能解析**（编译器报的却是一串看似无关的 `prefix ... is unknown`）。

* **规则**：示例里的颜色**一律用对象** `{r,g,b,a}`，**不要用 `#rrggbb`**；
* **防线**：写示例的脚本里加了断言 `'"#' not in body`；
* 本轮第一次尝试因此**撞坏过文件**，已 `git checkout` 回退后重做 —— **全程没有把红树推上去**。
