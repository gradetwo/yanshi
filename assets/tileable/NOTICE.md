# 可平铺纹理资产 —— **CC0 1.0** ✓（公共领域贡献 ✓，无需署名 ✓、可商用 ✓）

**为什么有这个目录** ✓：`assets/textures/` 是**运行时缓存**（由 `scripts/fetch-textures.sh` 抓取 ✓，
**不在 git 里** ✗）⇒ **离线与发布包拿不到纹理** ✗ ⇒ 需求文档 P1 ⑦ 的另一条路正是
「**加可平铺纹理资产**」✓ ⇒ 这里放**随仓库发出**的一小套 ✓。

**来源与派生（如实写 ✓）**：
  * 原始资产来自 **ambientCG**（<https://ambientcg.com/> ✓，许可见 <https://ambientcg.com/license/> ✓）
    的 **1K-PNG · Color** 变体 ✓ ⇒ **CC0 1.0** ✓；
  * 本目录里的文件是**确定性降采样**的产物 ✓：**等距抽样**（每 8 个像素取 1 个 ✓ ⇒ 1024 → 128 ✓）
    ＋ 用 zlib 手写的**最小 PNG 编码**（8 位 RGB、无过滤 ✓ —— 与本仓库自写的解码器相容 ✓）；
    **不用插值** ✗ ⇒ 同输入必同输出 ✓（确定性 ✓）；
  * 派生脚本是一次性工具（`docs/design/vermeer-acceptance.md` 里记了做法与判据 ✓）。

**尺寸与内容** ✓（每张 128×128 ✓，四张共约 100 KB ✓）：

| 文件 | 用途 | 大小 |
|---|---|---|
| `paper-fine-128.png` | 细纹纸（最平的底 ✓）| ~7 KB |
| `paper-fiber-128.png` | 纸纤维（略有起伏 ✓）| ~35 KB |
| `cardboard-128.png` | 纸板（粗一点 ✓）| ~27 KB |
| `canvas-128.png` | 画布（亚麻感 ✓）| ~30 KB |

**平铺性** ✓：判据 `scripts/tool-tileable-textures.mjs` 会**逐张量边缘与内部的像素差** ✓
（无缝要求"左右/上下边缘的差"与"内部相邻列的差"**同量级** ✓）⇒ 四张都通过 ✓。
