  >
  > —— Igor Novikov, sK1 Project ✓，
  > [CREATE 邮件列表 2015-06-17](https://lists.freedesktop.org/archives/create/2015-June/005085.html) ✓
* **代码出处** ✓：本次是从 [1j01/palettes](https://github.com/1j01/palettes) 的
  `sk1_palette_collection_1.0/GPL/` 取的文件 ✓（2026-10-02 ✓）。
  **⚠️ 该镜像自己声明"这些调色板不是我授权的"** ✗ ⇒ **我们依据的是上面 sK1 作者的 Public Domain 声明** ✓，

* **只收了 `.gpl`** ✓：这是标准文本格式（`GIMP Palette` 开头 ✓）。
  `.skp` / `.xml`（SCRIBUS / COREL）/ `.ase` / `.jcw` / `.cpl` / `.soc` **没有收** ✗ ——
  因为本项目**没有它们的解析器** ✗ ⇒ 收进来就是"报了却用不了" ✓（与刚修掉的灰度 PNG 那条同一类 ✓）。
