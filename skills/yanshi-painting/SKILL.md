# 大笔起手，一笔一块体积

## 这份 skill 解决什么

用 yanshi 画出来的图，最常见的两种失败观感：

1. **填色感** —— 像把线稿涂满。**直因**：用 `bucket` / `fill_region` 起稿，或用**大量小笔**堆满区域。
2. **一笔一笔看时不像手画的** —— **直因**：单笔**一个尺寸、一个不透明度**平铺，没有起收笔、没有笔内浓淡。

**∴ 问题不是引擎缺能力** ✗ —— 下面这些开关**本来就有**，只是没被用起来。

## 必须记住的六个参数（都是实测读出来的）

| 参数 | 值 | 作用 |
|---|---|---|
| `size` | **大**（覆盖笔刷自带半径，单位是直径像素） | **∴ 大笔起手靠它** |
| `humanize` | 缺省就是 `true` ⇒ **别关** | 没给压力时自动套**非对称起收笔包络**（起 12% / 行 60% / 收 28%） |
| `pressure_curve` | **`"auto"`（推荐）**，别用缺省的 `flat` | 按曲率自动分配压感 ⇒ 笔内有浓淡 |
| `glaze` + `glaze_passes` | `true`，遍数 3 起（**8 遍饱和**） | **罩染**：单笔自动拆成多遍**微偏移薄涂** ⇒ 皮肤 / 暗部的丝滑渐变 |
| `tremor` + `tremor_seed` | 0.2–0.5，**同种子同波形** | **生理颤动**（手腕 λ≈90px + 震颤 λ≈28px，沿局部法向） |
| `points` | `[[x,y,pressure,time_ms],…]` | 给**毫秒时间戳** ⇒ 引擎算**真实速度**（吃速度的笔刷才活） |

辅助：`dwell`（0..1，拐角多插点 ⇒ 颜料更足）、`color` / `color_to`（一笔内变色）。

## 作画流程（四遍，按顺序）

### 第一遍：大笔铺块面（这一步决定"不是填色"）

- **`size` 直接给大值**，把全幅拆成 **5–9 块**：背景 / 暗部 / 中间调 / 亮部。
- **每块 1–3 笔完成**，笔触**越过轮廓**（后面再收）。
- 大块之间的过渡**不要手拼**：用 **`gradient_blend`** —— 它就是"手动拼 20 笔"的服务端替代，且**逐笔调用同一条落笔实现**（与手画观感一致）。
- **禁用**：`bucket`、`fill_region` 起稿 ✗（填充只允许用于最后统一底色灰这一种用途）。

### 第二遍：压出体积

- 同色系大小笔交替，**顺着形体方向**走：盘发的旋、肩的弧、裙的垂。
- 暗部 / 皮肤用 **`glaze: true`** 罩出来，而不是一次涂死。
- 开启 `pressure_curve: "auto"` + `tremor`（带种子），让每一笔自身有浓淡与微颤。

### 第三遍：锚点收细节

- 只在**持久锚点**用小笔：脸、手、蕾丝、薄纱边缘。
- **∴ 小笔总数压到最低** —— 这既让画面真实（大笔是主体），又**压住对象数**（少笔 ⇒ 折叠开销不涨）。

### 第四遍：自检（"一笔一笔看"清单）

- [ ] 起收笔**看得见**（不是两端齐平）—— 若齐平 ⇒ 检查是否误关 `humanize`。
- [ ] 单笔**内部**有浓淡变化 —— 若没有 ⇒ 检查 `pressure_curve` 是否还是 `flat`。
- [ ] 大块面是**罩**出来的、能透出底色 —— 若一次涂死 ⇒ 用 `glaze`。
- [ ] 边缘**软硬不一**（不要一圈同样硬）。
- [ ] 全图**找不到"填满"的边界** —— 若找得到 ⇒ 说明起稿用了填充或小笔平铺。

## 反模式（明写，别做）

- ✗ 用 `bucket` / `fill_region` 起稿。
- ✗ 小笔先描边、再涂满。
- ✗ 单笔一个不透明度平铺大面积。
- ✗ 把 `humanize: false` 与 `pressure_curve: "flat"` 当默认（那是"精确复现控制点"用的，不是画画用的）。
- ✗ 一上来就抠细节（脸画得很准、块面是平的 ⇒ 观感立刻假）。

细节见 `references/anti-patterns.md`。

# 笔法不能只有大小：柔 / 薄 / 堆 / 刀

**症状**：笔触只有"大小粗细"的变化 ⇒ 整幅像**一层层平叠**，
最后**还能看见填色的边缘线** ✗，细节一模糊就偏 ✗。

**根因**：只用了 `size` 一个维度 ✗。油的画味来自**同一张画里同时出现厚薄软硬** ✓。

## 五样笔法（本仓的真实实现）

| 笔法 | 用什么 | 关键参数 |
|---|---|---|
| **柔（揉开、消边线）** | `smudge` 工具，或 **`classic-knife`** 笔刷 | **`smudge = 1.0`** ⇒ 把画布上**已有的颜色拖开** |
| **薄涂（透底）** | 任何笔画 | **`glaze: true`** ⇒ 单笔自动拆成多遍微偏移薄涂；`glaze_passes` 3 起，**8 遍饱和** |
| **堆（厚）** | `add_filter` | **`impasto`** |
| **层间融合** | `set_layer_blend` | — |
| **肌理** | `texture_background` / `list_textures` | — |
| **擦（干笔）** | **本仓没有这个参数** ✗ | 近似：`scatter_strokes` 低 `opacity_range` + 小 `size_range` |

## ★ 刀与揉有一个前提：**必须先有底色**

`smudge`（以及靠它工作的 `classic-knife`）是**涂抹类**——它**抹开画布上已有的颜色**。

**∴ 空白画布上它什么都不出，那是正确行为，不是坏了** ✓。

**∴ 所以顺序是有物理原因的，不是构图偏好**：

1. **先用大笔铺 5–9 块底色**（第一遍，`size` 给大，越过轮廓）；
2. **再用 `smudge` / `classic-knife` 把上下两笔的接缝揉在一起** —— 这一步**消掉"填色边缘线"和一层层叠加的痕**；
3. 需要透底的地方用 **`glaze`**，需要厚的地方用 **`impasto`** ⇒ **一张画里厚薄都有**；
4. **最后才在锚点收细节**。

## 细节精度：模糊要有边界

**脸 / 手 / 蕾丝不许被 `smudge` 扫到** ✗ —— 那是"一模糊就偏"的来源。
`smudge` 只允许用在**非锚点区**（背景、衣料大面、暗部过渡）。

## 选笔实证：没有“最佳万能笔”（2026-10-29 四大师审计）

来源：Yanshi-Brush-Study-20261029，基线 9c3b7d03（工具 208、笔刷 199），199 支逐支色样；未在当前 main 复测，条目为起点口径，正式采用前以目标部位试笔为准。

- 目前没有一支经整幅原作验收的「最佳万能笔」。正式采用须先在目标部位试 5–8 笔，确认体积、边缘、色彩与原作尺度，再分阶段推进。
- 阶段性起点（非整幅验收）：大块铺色 `oil-06-paint`；方向纹理 `Classic_Paint`（有方楔，不宜大面积）；破边肌理 `oil-01-paint`；细线 `2B_pencil` size2 连续，size14/24 颗粒过粗；精细候选 rigger_brush_thin、`soft-dip-pen`。
- 参数口径补记：显式传 `size` 会清除笔刷半径动力学，要保留动力学就别传 `size`；`pressure_curve: "auto"` 补的是未给变压时的包络，`points` 已带变压时 auto 不再改写（实测与非 auto 0 像素差异）；`humanize: false` 等于关掉起收笔补偿；`opacity` 是每 dab 墨量，不是整笔不透明度；`glaze` 是 boolean，遍数走 `glaze_passes`（1–8）。
- 橡皮类笔刷预览零墨不等于落笔失败：199 支中 7 支橡皮类预览零墨，属诊断口径问题（Y26-001，功能本身未解决），以实测落笔为准，不以预览零墨断定笔刷坏了。
- 智能工具边界：`smart_blend` 在小场景已很慢（512×320 两次约 22/31 秒），整幅 8K 不要默认用；`smart_glaze` 回执 ok 不等于可见效果，调用后必须目视验 ROI；`smart_hatch_follow` 三档均有 failed、部分绘制，先小范围试再决定用不用。

## 临摹方法实证：排线族与阈值轮廓填充（2026-10-30 两轮《祈祷的手》）

来源：第六轮分析（排线族，46,316 笔）与另一家包分析（`fill_region` 阈值轮廓填充，1,888 对象）。两轮目标不同、画布不同，只做目视与方法定性对比，不跨目标对打指标。Wang 目视已裁决：阈值轮廓填充一路效果好多了。

- 排线族一路（不推荐作素描临摹主路线）：全局固定角度排线族加方向缓变加残差判断。1:1 下读感像编织／雕刻纹理：边缘无长轮廓线锁定、呈毛刺状；同一线宽、同一间距致暗部漏白缝、灰面呈斑马纹；笔头齐切、无宽度收尖。弱点在通幅质感层，须改方法本身才能收窄。
- 阈值轮廓填充一路（当前目视最优）：按灰阶阈值提轮廓，用 `fill_region` 落闭合轮廓填充，分灰阶分层叠加。1:1 下轮廓线连续锁定边缘、无毛刺，排线走向顺形体弯曲、疏密不均。弱点在色调量化层：灰阶台阶感（阈值带边界在袖口与暗部可见）、最暗处呈实心块而非层层叠线、中调偏洗。
- 两路都不是人工逐笔手绘坐标：形状坐标均由程序对参考像素分析得到（阈值轮廓、方向场、残差判断）。报告、检查点、脚本头注必须明写此点，不许把程序提取的坐标说成手绘。是否接受这种轮廓辅助口径，由 Wang 定，skill 只列事实。
- 与上文反模式的关系：反模式禁的是大面积平涂式填充。阈值轮廓填充的形状是细窄的墨迹轮廓，不是平涂，故不在禁令内；但若把阈值填充用于大面积平涂，禁令照样适用。
- 下一步待验证方法（专家五步处方，参数已在主干 8176c265 核实，方法本身未跑过验证）：先做长轮廓结构线（骨架化取长脊线，轮廓线 40 像素以上保留），再做双频分离（软底 wash 加上层排线），再用流线积分做沿程弯曲的排线（每笔 40–120 像素 C 形弯曲），每笔做单侧起收笔包络，最后用选区裁剪去纸斑、用不透明度补偿细线。验证顺序：先跑 512×512 三区原型（大拇指、食指根部、右侧手背交界线），验收写成可目检的句子而不只报指标；原型未过不铺全幅。
- 处方参数口径（主干实测，错写即不生效或被夹紧）：`clip_to_selection` 传选区 id、latest 或 combined，不是布尔值；`smooth` 是布尔值，走 Catmull-Rom 重采样；`stroke_taper` 是 0–1 数值，不是布尔值，且在 wasm 里不生效；edge_soft 是 0–1 数值，硬度反向映射；tilt_shade 是 0–1 数值，线性映射到扁笔比例 1–3 与角度 0–45 度，传 45 会被夹紧到 1.0；`humanize` 传 false 等于精确坐标；`create_selection` 有 `from_mask`，蒙版可一键转选区，选区这一步不堵。注意：edge_soft 与 tilt_shade 是笔刷路径实际接受的意图参数，且已在 `brush_stroke` 注册表条目里声明，brush_stroke 语境下可加反引号（判据认已声明标识符）。
- 介质注意：处方参数走 `brush_stroke` 路径。`medium_stroke` 的参数表不含 tilt_shade、edge_soft、`stroke_taper`、`clip_to_selection`、`humanize`，在 medium 管线里用处方须换介质或补参数。
- 线宽量法（Day-1 先知测试已证）：显式传 `size` 会把宽度钉死在 size 附近，压感只控浓度；宽度反查必须用无 size 表且按笔刷分流；最小可用线宽 2 像素（随笔刷变），1 像素不存在。

## 全幅复现的分层采样 + 分块羽化拼接法（2026-11-01 全幅实测）

来源：半幅 1620×1920 与全幅 3240×3840 两轮实测。本节只写“笔数上到 20 万量级时怎么铺满又不露底”的铺法，不替代上文四遍流程——四遍是起手与收尾的顺序，本节是铺满的方法。

### 分层配方（全幅实测，笔尺寸为绝对像素）

| 层 | 笔宽 | 间距 | 色值抖动 | 适用区 | 全幅笔数 |
|---|---|---|---|---|---|
| 密底色层 | 18px | 20 | ±2 | 全幅 | 31,459 |
| 中笔层 | 10px | 13 | ±2 | 全幅 | 74,547 |
| 平坦补底层 | 12px | 14 | ±1 | 低梯度区 | 25,408 |
| 细笔层 | 5px | 10 | ±3 | 全幅 | 49,937 |
| 锐边层 | 3px | 7 | ±3 | 边缘区 | 20,374 |
| 细节区加密层 | 2.2–4.5px | 3–6 | 0（精确色） | 细节区 | 35,875 |

- 采样点落在间距网格上，另加 ±0.45 倍间距随机偏移；笔向顺局部方向场，细节区可用固定方向。
- 笔长约笔宽的 2–3 倍（密底色与中笔约 3 倍，余层约 2–2.5 倍）。
- 低梯度区定义：梯度值低于全幅 40% 分位、且不在细节区内的区域。

### 精确色规则：细节区不许过色板

- 初版教训：半幅初版用 96 级全局色板量化取色，细节区小面积色相被吃掉，浅色区发白发花；改细节区取原像素精确色后解决。
- 全幅规则：禁用全局色板，全部图层取原像素精确色；非细节层保留上表色值抖动，细节层抖动为 0。
- 覆盖教训：初版密底色 16px@26、中笔 9px@15 在平坦区盖不住，块核心距底色均色 10 以内占 8.0%；改为 18px@20、10px@13 并加平坦补底层后，同口径降到 2.3%。

### 平坦补底层的作用

- 平坦补底层只铺低梯度区，专治“针孔露底”：大笔间距在低梯度区留下的底色透点。
- 半幅加补底层后平坦区目视无针孔；全幅沿用同一层，平坦区目视同样无针孔。
- 补底层不是加厚全幅：它只进低梯度区，不进细节区与边缘区，否则细节会被糊掉。

### 分块与拼接纪律

- 全幅 327 块：12×14 核心网格 + 递归四分，70px 最小块停分；落笔实例 449,794；最大块 2,744 笔，中位 1,372 笔。
- 块独立绘画、断点续跑（跳过已出块）；块内失败只重跑该块，不动已成块。
- 拼接前验：块数齐（327/327）、零零字节、零损坏；缺块不拼接。
- 块与块之间羽化拼接，不留硬缝。

### 时间模型（实测值，不是承诺值）

- 全幅 3240×3840：237,600 笔，绘画 7,167 秒（约 119.5 分钟），零失败。
- 半幅 1620×1920：59,969 笔，绘画 1,342 秒，零失败。
- 笔数与耗时随目标复杂度与分块走，以上两数只是这两轮的实测，不作他图的承诺。

### 方法固有残差

- 离散笔触表面质感 vs 薄涂 blended wash：细节区与平坦区在 1:1 与 3 倍下仍见细颗粒感，全幅比较半幅收窄、未消除。
- 个别深色加重处略重。
- 以上两项是本方法的固有残差，不是参数没调对；再调参数收不掉，只能换方法。

- 验收以眼睛 1:1 + 3 倍为准，数字只作诊断。
