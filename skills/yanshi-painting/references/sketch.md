### R-03 sRGB 到 linear 分段换算（S-08）

- 规则正文：brush_stroke 的 color 数组 0..1 分量会被当 linear 解。
- 规则正文：渲染转 sRGB 会提亮。
- 规则正文：想画目标 sRGB 色，先经 sRGB 到 linear 分段换算再发。
- 实证来源：残差程序的 srgb_to_linear 函数。
- 确切参数：分段点 v = 0.04045。
- 确切参数：v 小于等于 0.04045 时，linear 等于 v 除以 12.92。
- 确切参数：v 大于 0.04045 时，linear 等于 ((v + 0.055) / 1.055) 的 2.4 次方。
- 确切参数：换算后取四位小数再发。
- 确切参数：颜色数组第四分量是 1.0。
- 实测数值：见附录 §R-03。
- 实测数值：附录收第一阶段偏亮的采样值与换算算例。
- 阈值推导：分段点 0.04045 与指数 2.4 是标准 sRGB 分段公式常数。
- 阈值推导：本轮未推导常数，只复用公式。
- 失败情形：不换算直接发 sRGB 值，颜色偏亮。
- 失败情形：第一阶段洗笔即因此偏亮。
- 适用条件：目标色以 sRGB 给出。
- 适用条件：引擎把 0..1 当 linear 解。
- 不适用条件：目标色已是 linear 值。
- 不适用条件：引擎改用 sRGB 直通口径。
- 证据出处：见附录 §R-03。
