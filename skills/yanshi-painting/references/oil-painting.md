# 油画临摹方法 v5（通用版）

- 本文件是 v5（Wang 2026-10-29 批准发包），由 v4 草案修订。
- v3 原文未动（工作区 v3 文件指纹复核 4/4 OK，见同目录 genericity-check.md）。
- 第 2 轮证据基线：binary 9c481d63（修复程序期 1–7）。
- 正文只写通用泛化内容，不写画名与画内具体部件；画的具体细节只在证据附录。
- 标注“暂定，第 3 轮校准”的阈值是提案，不是已验证事实。
- 未复测项不作事实，列入末节第 3 轮量测。
- 结构：v3 规则保留（勘误处标），之后是“v4 新增规则”、“第 3 轮量测”与“v5 更新”三节；v3 补测节保留作历史。

- 本文件是油画临摹方法草案通用版。
- v3 规则号不变，共 23 条；v4 新增规则另编号，不混入 v3 规则号。
- 每条规则带八项：规则正文、实证来源、确切参数、实测数值、阈值推导、失败情形、适用条件与不适用条件、证据出处清单。
- 证据出处只指证据附录的对应节。
- 本文件不写画名，不写画内具体部件名。
- 部件只用材质或技法类表述，例如厚涂区、远景区、亮部。
- 画布定法：长边取源图长边像素数，宽高比取源图宽高比，不另设尺寸。
- 定位定法：全部坐标写画布分数，不写绝对像素。
- 分数换算：分数等于绝对像素除以画布对应边长。
- 全文中文加 ASD-STE100 格式，一句话一个意思，句子要短，一件事写一行。
- v3 勘误三处见各规则内“勘误”行；v4 勘误见各规则内行与 ERRATA-v4.md。
- 适用范围：长边约 4K 的画布上的厚涂油画临摹，全部落笔走 Yanshi MCP。
- 盒子纪律沿用常驻规则：一台盒子同一时刻只跑一条重任务。

### R-02 落笔与内存成本模型

- 规则正文：用成本模型估算落笔时间与内存，50,000 笔档不画。
- 实证来源：探针拟合，见附录 §R-02。
- 确切参数：落笔总时间 T(N) = 1,628 秒 × (N/10,000)^2.048。
- 确切参数：连续会话内存 RSS = 0.189 MB/笔 × N + 15.7 MB。
- 确切参数：每批耗时（每批 200 笔）batch_sec = 0.004287 × N^1.048。
- 确切参数：工程包大小约 1.48 KB/笔。
- 实测数值：拟合用干净文档 45 批数据，N≥1,000，log-log 回归。
- 实测数值：T(10,000) 拟合值 1,628 秒，实测值 1,598.1 秒，误差 1.9%。
- 实测数值：10,000 笔档 RSS 峰值 2,009.9 MB，公式值 1,905.7 MB，相差约 104 MB，原因未解释。
- 实测数值：50,000 笔外推落笔 43,968 秒（12.2 小时），外推 RSS 约 9,475 MB，超盒子内存 7,964 MB，结论 NO-GO。
- 实测数值：100,000 笔外推落笔 181,817 秒（50.5 小时），结论 NO-GO。
- 实测数值：500,000 笔外推落笔 4,910,148 秒（1,364 小时），结论 NO-GO。
- 实测数值：油画实测批耗时与探针模型之比约 0.8–1.0 倍。
- v4 实测数值：第 2 轮出口已是秒级：export_png 约 5 秒、export_project 约 8 秒（20,000 笔档，binary 9c481d63）。旧分钟级出口数退役。
- v4 实测数值：第 2 轮单会话内存上限实测：约 18,800 笔撞 4,096 MB 上限（见附录第 2 轮证据节）。第 3 轮在新 release 上重测成本模型与约 21,000 笔重开上限。
- 阈值推导：回归因变量未记录（每批秒数还是累计秒数），残差与 R² 未记录，写未验证。
- 阈值推导：1,000 笔档与 5,000 笔档无拟合值对照，验证只在 N=10,000 一个点。
- 阈值推导：重开估算 0.293 MB/笔无量测出处，不作规则，见补测节 X-12。
- 阈值推导：21,000 笔上限是 6,144÷0.293 的商，6,144 MB 预算选取依据未写，不作规则，见补测节 X-13。
- 阈值推导：各画各阶段实测批耗时对照表未建，只给比值范围，写未验证。
- 失败情形：N 超 36,000–42,000 笔时连续会话 RSS 触到盒子内存上限。
- 适用条件：模型用 oil-06-paint、size 30 合成笔触拟合，探针画布长边 4K、宽高比 16:9。
- 不适用条件：其它笔刷与尺寸未标定，不直接套用本模型。
- 证据出处：附录 §R-02。

## §1 环境与会话

### R-04 内存预算与导出目录

- 规则正文：启动服务器前设内存预算 6,144 MB，设导出目录指向工作目录。
- 实证来源：探针 §8-4 与油画工程包导出记录，见附录 §R-04。
- 确切参数：设 `YANSHI_DOC_MEMORY_BUDGET_MB=6144`。
- 确切参数：导出目录指到工作目录，取值见附录 §R-04。
- 实测数值：10,000 笔文档在缺省预算 2,048 MB 下拒绝新鲜打开，错误码是 `resource_exhausted`。
- 实测数值：探针报告 §8-4 写该文档估算内存 2,930 MB。
- 实测数值：20,000 笔文档在预算 6,144 MB 下重开成功，两次 export_png 逐位相同。
- 阈值推导：6,144 MB 预算的选取依据未写，不作规则，见补测节 X-13。
- 阈值推导：2,930 MB 估算值的每笔换算依据无量测出处，不作规则，见补测节 X-12。
- 失败情形：预算不足时重开被拒，须关掉不用文档或调高预算。
- 失败情形：导出路径只写导出目录或 /tmp，写工作目录会被守卫拒绝。
- 适用条件：重开 10,000 笔以上文档时须设预算。

- 证据出处：附录 §R-04。

### R-05 会话纪律

- 规则正文：同一会话先打开文档，再发 batch；一个会话只发一次 initialize；一个文档根目录只跑一个服务器进程。
- 实证来源：探针 §8-1、§8-2、§8-6，见附录 §R-05。
- 确切参数：打开文档用 `list_layers` 或 `get_document`。
- 确切参数：`initialize` 在一个会话里只发一次。
- 实测数值：驱动重复发 initialize 后 batch 全部失败，错误只有 `unknown`，失败数等于调用数。
- 实测数值：同一会话不先打开文档，batch 报 `reference_not_found`。
- 实测数值：两个进程共用同一 root 写出 400 个重复原子，引擎没有加锁。
- 实测数值：batch 忽略每次调用的 doc_id，用会话当前活动文档。
- 阈值推导：无阈值推导，本规则是会话纪律。
- 失败情形：重复 initialize 破坏 batch 时，驱动侧无法从 `unknown` 识别原因，须重开会话。
- 失败情形：新会话不先打开文档时，笔落错文档或被拒。
- 适用条件：全部落笔会话都守本规则。
- 不适用条件：无不适用条件。
- 证据出处：附录 §R-05。

- 阈值推导：无阈值推导，本规则是开关取舍。
- 失败情形：指望两个开关调浓淡时，渲染无变化，须改给显式压力。

### R-08 大笔成本上限

- 规则正文：大笔铺块面只用 oil-01-paint，size 取 200，路径不超 2,300 像素。
- 实证来源：二分量测，见附录 §R-08。
- 确切参数：oil-01-paint 的 reads_canvas 是 True。
- 确切参数：路径上限是 2,300 像素。
- 确切参数：成本约正比于路径长 × 尺寸²。
- 实测数值：size 60、路径 2,000 像素时单笔 2,342 毫秒，delta 33。
- 实测数值：size 200 时单笔约 25 秒（量测值 24,990 毫秒），delta 255。
- 实测数值：size 650、路径 4,240 像素时 7 分钟以上未完成，已杀掉。

- 失败情形：size 650 单笔卡死时，杀驱动与服务器，文档与锚点仍在根目录，可重开续画。
- 适用条件：大笔铺块面时用本规则。
- 不适用条件：批量重磨不用 oil-01-paint，见 R-09。

## §3 颜色与单位

### R-10 颜色换算与单位陷阱

- 规则正文：颜色用 3 分量 0..1 加 color_space:"srgb"，hex 转 0..1 时除以 255，取四位小数。
- 实证来源：油画第一阶段生成器，见附录 §R-10。
- 确切参数：换算公式是每通道 round(int(hex 两位，16 进制）/255, 4)。
- 确切参数：color 只用 3 分量，4 分量触发 `color.a` 警告。
- 确切参数：`color.a` 有效，乘进 opacity；要淡可用 `color.a` 或 `opacity`（K-1，旧“被忽略”已推翻）。
- 确切参数：`background` 是 0..255 的对象。
- 确切参数：`points` 第 3 槽永远是压力，不是 time_ms。
- 实测数值：输入 [0.18, 0.29, 0.49] 采样回 [46, 74, 125]，与目标一致。
- 实测数值：不传 color_space 时缺省按 linear 解释，同值会变亮。
- 实测数值：selftest 正常一笔因 4 分量颜色多 1 条 warnings，基线是 0 条。
- v4 实测数值：第 2 轮四图探针一致：a=10 时 delta=70，a=250 时 delta=235；warnings 由 1 变 0（K-1，binary 9c481d63）。
- 阈值推导：无阈值推导，本规则是单位换算。
- 失败情形：4 分量颜色不再警告；透明度生效（K-1）。
- 失败情形：不传 color_space 时颜色变亮，须重画。
- 适用条件：全部落笔颜色都走本换算。
- 不适用条件：字节色路径未验证，不套用本规则。
- 证据出处：附录 §R-10。

### X-1 构图落位

- 规则正文：落笔前先量全部关键结构的位置，落笔后复核，不许事后宣称位置对。
- 规则正文：关键结构清单先目读参考图列出。
- 确切参数：每个结构在参考图上量分数坐标（x/W、y/H，取结构中心 + 包围盒）。
- 确切参数：换算到画布坐标（×画布尺寸），写入量测记录；落笔前完成。
- 确切参数：里程碑 1 渲染后复核：渲染中结构中心与记录坐标比对，逐项列出偏差（百分点）。

- 失败情形：落位失败不停线继续，偏差会带入终版。
