# 反模式与诊断表

## 症状 → 直因 → 改法

| 症状 | 直因（本仓实测） | 改法 |
|---|---|---|
| 像"把线稿涂满" | 起稿用了 `bucket` / `fill_region`，或大量小笔平铺 | 第一遍改用**大 `size`** 的 1–3 笔一块；块间过渡用 `gradient_blend` |
| 一笔一笔看没有手画感 | 单笔一个尺寸 / 一个不透明度 | `humanize: true`（缺省）+ **`pressure_curve: "auto"`** + `tremor` |
| 两端齐平、像马克笔色块 | `humanize: false`，或显式给了**恒定** pressure 却没给曲线 | 别关 `humanize`；若必须给压力，就配 `pressure_curve: "auto"` |
| 暗部 / 皮肤发闷、像贴色纸 | 一次涂死，没有透底 | `glaze: true`，`glaze_passes` 3 起（**8 遍饱和**） |
| 边缘一圈同样硬 | 全程同一支笔、同一尺寸 | 大小笔交替；第二遍**顺形体方向**，不要描边 |
| 细节很准但整幅是平的 | 一上来就抠细节（顺序错了） | 回到第一遍：先 5–9 块，再压体积，最后才收细节 |
| 笔数极多、越画越慢 | 小笔堆量 ⇒ 对象数随笔数涨 | **大笔少笔**（起稿 ≤ 3×块数）；这也是本仓记录过的"每笔折叠开销"痛点的**治本**解 |

## 顺序纪律

**块面 → 体积 → 锚点细节**。跳步（先细节）一定会得到"填色感"，
因为**块面是平的**，细节再准也救不回来。

## 什么时候才用"精确模式"

`humanize: false` 与 `pressure_curve: "flat"` 是给**确定性像素判据**用的
（要逐字节复现控制点）。**作画时不要用**。
