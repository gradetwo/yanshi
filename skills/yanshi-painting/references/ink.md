## 规则 3：颜色走线性光，意图值先换算（补 I-04）

- 正文：意图值先换算成线性值，再传给 brush_stroke。0..1 浮点颜色是线性光。
- 实证来源：重做主脚本换算函数。首试残差脚本换算函数。首试笔记诊断根因 1。
- 确切参数：公式：c = s/255。c ≤ 0.04045 时返回 c/12.92。否则返回 ((c+0.055)/1.055)^2.4。色表（sRGB 输入）：PALE (196,184,158)。WASH_L (176,163,138)。WASH_M (148,136,114)。WASH_D (118,106,88)。INK (84,75,60)。INK_D (58,52,42)。BLACK (38,34,28)。SEAL (172,58,40)。纸色：首试 (211,193,163)。重做 (215,198,168)。
- 实测数值：三组换算实例：淡墨 sRGB (0.72,0.68,0.60) → 线性 (0.48,0.42,0.32)。中墨 (0.55,0.51,0.44) → (0.26,0.22,0.16)。暗墨 (0.38,0.35,0.30) → (0.12,0.10,0.07)。自检蓝笔 [0.2,0.3,0.6] 采样 [124,149,203]，等于线性→sRGB 换算值。
- 阈值推导：无阈值。换算公式是标准 sRGB 分段公式。
- 失败情形：按 sRGB 意图直接给值，偏淡约 1.6 倍。淡墨落在纸色上几乎看不见。相对位置 (0.244,0.234) 处采样 [213,197,170]，近纸色。绝对坐标见证据附录 §规则 3。
- 适用条件：全部 brush_stroke 颜色。全部三档墨色。
- 不适用条件：background 对象。background 用 0..255 整数对象，不走此公式。
- 证据出处：证据附录 §规则 3。

## v4 新增规则（通用）

### X-1 构图落位

- 规则正文：落笔前先量全部关键结构的位置，落笔后复核，不许事后宣称位置对。
- 规则正文：关键结构清单先目读参考图列出。
- 确切参数：每个结构在参考图上量分数坐标（x/W、y/H，取结构中心 + 包围盒）。
- 确切参数：换算到画布坐标（×画布尺寸），写入量测记录；落笔前完成。
- 确切参数：里程碑 1 渲染后复核：渲染中结构中心与记录坐标比对，逐项列出偏差（百分点）。
- 阈值推导：任一轴偏差 >10 个百分点 = 落位失败，须纠正后继续（暂定，第 3 轮校准）。
- 阈值推导：阈值锚点：第 2 轮基本在位结构最大偏差约 5.7 点、在位外结构最小偏差约 17.5 点，阈值取 10 点。
- 失败情形：无量测记录的位置句不算证据。
- 失败情形：落位失败不停线继续，偏差会带入终版。
- 适用条件：全部关键结构。
- 不适用条件：无量测记录时不落笔。
- 证据出处：证据附录第 2 轮证据节。
- 拟合几何锚点量测方法并入本规则：初值 + 网格搜索细化 + 命中率比选；长直边从追踪折线量取。

### X-2 自检证据（防呆）

- 规则正文：每个通过断言须附量测值 + 分区图文件名；无像素证据的泛泛句不算通过。

- 规则正文：3x 可见缺陷 = 分区不通过，绝不降格为残留。
- 规则正文：1:1 整图一眼裁决独立成项，可推翻分区得分。
- 规则正文：自检须列残留缺陷清单；无残留清单的“全部通过”不采信。
- 规则正文：执行 agent 自检是主张、独立 1:1 + 3x 复核是裁决；交付须附分区裁切图 + 量测记录，否则复核无法进行。
- 实证来源：第 2 轮连续推翻记录（见附录第 2 轮证据节）。
- 失败情形：自检断言无证据文件时，该断言不采信。
- 适用条件：全部自检断言。
- 不适用条件：无。
- 证据出处：证据附录第 2 轮证据节。
